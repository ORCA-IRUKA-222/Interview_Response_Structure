# 面接ノート (Interview Response Structure)

面接の **質問と回答を構造化して保存** し、**GitHub の secret Gist でスマホと PC を同期** する Web アプリです。
サーバーは不要（静的サイト + ブラウザから GitHub API を直接呼びます）。PWA なのでスマホのホーム画面に追加すればアプリのように使えます。

## できること

| 機能 | 説明 |
| --- | --- |
| **深掘りの構造化** | 回答の一部を**範囲選択**すると、その箇所に紐づく深掘り質問を作れます。深掘りにも回答があり、さらに選択して何階層でも掘れます。親の回答では深掘りのある箇所がハイライトされ、タップでその質問へ飛べます |
| 引用の追従 | 回答を書き換えても、引用テキストを探し直して深掘りの位置を追従します（消えた場合は「回答から消えました」と表示） |
| **単語帳** | 質問をタップするとカードがめくれて「話す要点」「回答」「想定される深掘り」が出ます。「言えた／もう一度」で復習間隔（ライトナー式 0/1/3/7/14 日）を管理 |
| **カラオケ** | 発表アシスタントと同じ追従ロジックを移植。回答（または要点）を話すと、読んだ部分が**赤**に、いま読んでいる文が強調されます。タップで読み始め位置を指定、文単位の手動送りも可 |
| 検索 / タグ | 質問・回答・要点・タグを全文検索（全角半角・ひらがなカタカナ・大小文字を区別しない、空白区切りで AND）。タグで絞り込み |
| エクスポート | JSON（完全バックアップ・取り込み可）と Markdown（面接ごと / 全体） |
| Gist 同期 | 下記参照。オフラインでも使え、オンラインに戻ると同期 |
| レスポンシブ | PC は 3 カラム（面接 / 質問ツリー / 詳細）、スマホは 1 画面ずつの画面遷移 |

## 使い方

1. 「＋ 追加」で**面接**（企業・選考）を作る
2. 質問を追加し、回答を書く（「話す要点」は単語帳の裏面用に 1 行 1 項目で）
3. 回答を「選択して深掘り」モードにして、文字をなぞる → 深掘り質問を入力 → 「深掘りを作る」
4. 「単語帳」で覚える、「🎤 カラオケ」で声に出して練習する

## Gist 同期のセットアップ

1. [GitHub でトークンを発行](https://github.com/settings/tokens/new?scopes=gist&description=interview-note)（権限は `gist` のみ）
2. アプリの「設定」でトークンを貼り付けて「接続して同期」 → **secret gist** が自動作成されます
3. 2 台目以降は同じトークンと、設定画面に表示される **Gist ID** を入力

- データは Gist 内の `interview-qa.json` 1 ファイルです（Gist のリビジョン履歴から過去の版も辿れます）
- トークンは端末のブラウザ（localStorage）にだけ保存され、`api.github.com` 以外へは送信されません
- 競合は**自動統合**します（ダイアログなし）: 質問・面接を id 単位で `updatedAt` が新しい方を採用し、削除は墓標で伝えます。同じ質問を 2 台で同時に別々に編集した場合は後に保存した方が残ります
- 端末の時計がずれていると新旧判定がずれるので、時刻は自動設定にしておいてください
- 編集の 2.5 秒後、起動時、タブに戻ったとき、オンライン復帰時、開きっぱなしの場合は 1 分ごとに同期します

## 公開（GitHub Pages）

既定ブランチに push すると `.github/workflows/pages.yml` がテスト・ビルドして Pages にデプロイします。
初回のみ、リポジトリの **Settings → Pages → Source を「GitHub Actions」** にしてください。

## カラオケ（音声認識）の対応環境

ブラウザの Web Speech API を使います。**PC / Android の Chrome・Edge** で動作します（マイク許可と通信が必要。認識はブラウザ側のサービスで行われ、このアプリは録音しません）。
Firefox や、環境によっては iOS Safari は非対応/不安定です。その場合も「◀ 文 / 文 ▶」の手動送りは使えます。

追従ロジック（`src/lib/text/`）は Android 版「発表アシスタント」の `core`（`ScriptAligner` ほか）を TypeScript に移植したものです。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト (vitest)
npm run build      # 型チェック + 本番ビルド (dist/)
```

```
src/
├── types.ts            データ型（Interview / Question / Anchor …）
├── lib/
│   ├── model.ts        作成・ツリー化・引用の追従 (remapAnchor)
│   ├── merge.ts        端末間の統合（純粋関数）と JSON の検証
│   ├── gist.ts         Gist API クライアント
│   ├── sync.ts         同期の制御（pull → 統合 → push）
│   ├── store.ts        状態・localStorage 保存・変更操作
│   ├── search.ts / exporter.ts / srs.ts
│   ├── speech.ts       Web Speech API の連続認識ラッパー
│   └── text/           発表アシスタントから移植（正規化・アライメント・文境界）
└── ui/                 Preact の画面
```
